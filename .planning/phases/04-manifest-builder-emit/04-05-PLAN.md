Iterate parameter NAMES in deterministic `${(@ok)parameters}` order; for each name read its type descriptor from `$parameters[$name]`, skip reserved `ZP__*` names and any descriptor matching `*special*`, `*tied*`, `*hide*`, or `undefined`, then dereference its actual LIVE value with zsh `(P)` indirection. Do not serialize the `parameters` association's descriptor values as if they were live parameter values. Serialize by type and fail on any unhandled non-filtered type: scalar/integer/float records carry section tag, name, exact type, and value; indexed-array records carry tag, name, type, element count, then every 1-based index and value in order (including empty elements); association records carry tag, name, type, key count, then sorted keys and their indirectly dereferenced values.

    Arbitrary zsh scalar/array/association/PATH values may contain raw NUL, so do NOT use raw NUL as their record delimiter. Encode every string field independently with zsh's deterministic, reversible `${(qqqq)value}` representation and write one encoded field per newline, with plain structural tags/counts between fields. This turns embedded NUL/newline/backslash into visible escapes and makes boundaries collision-safe without interpreting the data. Use the same escaped-field encoding for parameter names/types, association keys, alias/function bodies, PATH elements, and ZP_BASE_PATH; numeric counts/indexes remain canonical decimal lines. The snapshot is compared byte-for-byte and never eval'd or decoded.

    Concatenate those real parameter records with dedicated sections for: aliases sorted with `${(@ok)aliases}` and exact bodies; options sorted with `${(@ok)options}` and explicit on/off state; functions sorted with `${(@ok)functions}` and exact bodies; PATH's ordered array contents, `$#path`, and deterministic per-element occurrence counts; and exact persistent `ZP_BASE_PATH`. PATH/path and the zsh parameter-module maps are dedicated because tied/special filtering excludes them from the generic section. Raw NUL framing remains forbidden for arbitrary values even if the existing introspection body protocol uses it at a separately proven parse boundary.

| live zsh state -> test snapshot | Volatile/special parameters can create false differences or mutate when read. | Filter by parameter type class before dereferencing and capture through files/fds; dedicated sections cover filtered admitted classes. |
| state -> serialized oracle | Raw NUL/newline data, hash order, and PATH duplicates can hide a real difference. | `${(qqqq)}` escaped fields, sorted associative keys, exact bodies/values, ordered PATH plus count and duplicate counts. |
| renderer mutant -> process | A quoting mutant intentionally exposes code execution. | Run with an isolated temp canary and inert fixture paths; assert the canary outcome, restore seams immediately, never touch user shell configuration. |

No live shell configuration or user environment is modified; every execution is a disposable `zsh -f` child.
</threat_model>
