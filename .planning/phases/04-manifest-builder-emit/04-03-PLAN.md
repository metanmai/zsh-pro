  <action>
    For every parsed scalar assignment and alias, assign exactly one non-legacy ValueMode. If wordIsDynamic is true, set Dynamic mode and preserve raw Value. Otherwise run a recursive decoder that accepts only: unquoted `*syntax.Lit` using its AST-decoded Value except a leading unquoted tilde form; ordinary `*syntax.SglQuoted` only when `Dollar == false`; and `*syntax.DblQuoted` only when all nested parts are accepted literal nodes. Concatenate adjacent accepted parts so `a' b'"c"` is one runtime value. Reject as Unsupported: `$'...'` ANSI-C quotes (`SglQuoted.Dollar == true`) until their zsh escape semantics are explicitly implemented; leading unquoted `~`; brace expansion, extglob, arithmetic/process/command/parameter expansions not already Dynamic; and every unknown WordPart. Unsupported is fail-closed data for the activation builder, not a parse error and not a legacy fallback.

    For aliases, decode the full AST word then remove only the exact leading decoded `name=` prefix associated with that argument; bodies may contain additional equals signs. Continue to preserve the source substring after `=` in Value. For every admitted one-name FuncDecl, use `c.Body` as `*syntax.Stmt` and create assignment-ready body text by AST form. Strip the outer braces and slice strictly between `block.Lbrace` and `block.Rbrace` ONLY when `c.Body.Cmd` is `*syntax.Block` and the Body statement is plain: no Redirs, no Negated/Background/Coprocess/Disown flags, and no other valid statement-level modifier/terminator that contributes behavior. That plain case makes `foo(){}` present-empty. If a block has any statement-level modifier (for example `foo() { print hi; } >file`), or the body is any other valid compound/simple form, slice the entire original `c.Body.Pos()` through `c.Body.End()` span. This retains braces plus redirects, parentheses in `foo() ( print hi )`, and keywords in conditional bodies. Store the result in a non-nil FunctionBody and keep Value as the full declaration. Only malformed/missing bodies or declarations rejected by the existing one-safe-name routing contract may have nil body presence; do not silently narrow `routeManaged`'s admitted KindFuncDecl forms.

    Tests: single/double/concatenated quotes, escaped quote/backslash as represented by AST Lit values, `FOO=''`, alias body containing `=`, single-quoted `$HOME` as Literal, unquoted `$HOME` as Dynamic, `$'\n'` as Unsupported, `FOO=~` as Unsupported, brace/extglob unsupported, empty `foo(){}`, a multiline brace body containing braces/comments, a subshell body `foo() ( print hi )`, and a redirected brace body `foo() { print hi; } >file`. Assert the redirected FunctionBody retains braces and redirect, while the plain block retains only its interior. Assert parsing performs no execution and source Value remains byte-identical.

<threat_model>
## Trust Boundaries

| Boundary | Risk | Mitigation in this plan |
|---|---|---|
| source word -> runtime data | Decoding could execute or over-interpret untrusted syntax. | AST-only allowlist, explicit Unsupported mode, no shell/interpreter/environment/filesystem expansion. |
| old profile JSON -> new builder | Missing fields could be mistaken for a newly verified literal. | Zero ValueMode is explicitly Legacy; every new parser path writes a non-legacy mode. |
| function source -> body text | An empty body can be confused with missing data, or compound/redirect syntax can be dropped. | Pointer presence; strip only a plain unmodified `*syntax.Block`; retain any modified block and every other Body statement span verbatim; tests cover empty, nested/multiline, subshell, and redirected bodies. |

No new dependencies or package-manager operations are permitted.
</threat_model>
