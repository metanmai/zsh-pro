## Explicit assumptions

- **A-01 (SW-01 adjacency):** The sources do not specify semantics for list values whose expanded elements touch or collide. This closure preserves the existing semantic-list contract and rejects unrepresentable forms rather than inventing collision behavior.
- **A-02 (SW-01 empty):** The sources do not specify empty, single-element, or null list behavior beyond the existing presence-aware model. This closure must not broaden that contract; rejected source creates no list operation.
- **A-03 (SW-01 ordering):** Equal-element ordering has no new written rule. Existing source order and semantic `ListValue` order remain authoritative; this closure must not normalize or deduplicate them.
- **A-04 (SW-02 unclassified):** No separately classified SW-02 behavior was supplied for automated coverage. The existing full-state oracle remains the manual-review anchor; this plan adds deterministic source-form regressions without claiming a new state class.
