<interfaces>
- `IngestCommitOutcome.PublishedRevision *string` is present only with authoritative committed/recovery evidence and is defensively copied/validated.
- `WorktreeMaterializer` receives the committed redacted full Profile plus exact branch/OID and delegates projection/materialization to the public composition-root Service.
- `main.go` creates one concrete zsh provider value, passes it to `worktree.NewRegistry` as LiveSecretPolicy for the public Service, opens that Service with Plan 07-03 `OpenStateStore(path)`, seeds durable ownership during Materialize, and configures a `RuntimeWorktreeFactory` that later constructs operation-scoped StateStore/Service values through `NewStateStoreFromAuthenticatedRoot` with the same provider policy after runtime validation/authentication.
- Public and runtime Service values may be distinct Go objects; they must address the same authenticated canonical combined `worktree.json` generation, which is the single durable authority. Runtime construction may neither reuse a pre-authenticated path-bound StateStore nor reopen a pathname. The descriptor constructor duplicates/re-authenticates the RuntimeRoot descriptor, the StateStore owns/closes only that duplicate, and the runtime outer scope retains/closes the input exactly once.
- Private Service request contracts and capability verification come directly from Plan 07-03. The factory/adapter forwards presented credentials but owns no alternate verifier, pre-lock authorization decision, or credential fallback.
</interfaces>
