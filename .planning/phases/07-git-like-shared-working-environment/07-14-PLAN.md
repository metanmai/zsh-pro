## Trust Boundaries

| Boundary | Description |
|---|---|
| shell-neutral patch -> executable zsh | Validated operations become parent-shell mutations carrying potentially secret values. |
| emitted apply -> loader ownership globals | Partial mutation crosses into recovery-critical state before acknowledgement. |
| failed transition -> public deactivate | A user-visible recovery command consumes retained reverse authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-14-01 | Tampering | emitted forward sequence | high | mitigate | Explicit per-operation status guard and real-zsh early/middle/final failure tests prevent masked partial mutation. |
| T-07-14-02 | Tampering | recovery-owner promotion | high | mitigate | Preflight and install replacement recovery before apply; retain old owner until successful promotion; block layering while recovery is pending. |
| T-07-14-03 | Information Disclosure | reverse/source/error globals | high | mitigate | Protected eval, value-free diagnostics, source/reply clearing, exact function cleanup, and canary assertions after every exit. |
| T-07-14-04 | Repudiation | failed apply/capture/ack | high | mitigate | Applied revision advances only after exact fresh-snapshot acknowledgement; all earlier failures retain behind/error and operation metadata. |
| T-07-14-05 | Denial of Service | failed reverse | high | mitigate | Existing absolute deadline remains active; public retry is idempotent and fail-open with no unbounded helper wait. |
| T-07-14-06 | Elevation of Privilege | public recovery surface | high | mitigate | Deactivate can invoke only loader-owned safe-name reverse functions already emitted for the authenticated pending transition; no user-selected function name. |
| T-07-14-07 | Spoofing | stale reply/active function | high | mitigate | Fresh exact reply fields and safe generated names are required; stale/partial globals are cleared before/after every operation. |

ASVS L1 gate: every high-severity mitigation above is blocking; the plan is incomplete until its automated proof passes.
