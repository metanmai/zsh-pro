## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-12-01 | Tampering | marker create/read/unlink | high | mitigate | Fixed descriptor-relative no-follow operations, owner/type/mode/content authentication, lock binding checks, file and directory sync. |
| T-07-12-02 | Information Disclosure | marker/errors/tests | high | mitigate | Constant value-free payload and generic diagnostics; canaries forbidden from marker, errors, logs, and retained fixtures. |
| T-07-12-03 | Repudiation | projection/clear ordering | high | mitigate | Clear only after durable canonical projection; crash/retry may repeat truth but cannot erase it early. |

| T-07-12-07 | Elevation of Privilege | recovery evidence | low | accept | The marker changes only truthful status/error evidence and grants no shell capability or state mutation authority. |
