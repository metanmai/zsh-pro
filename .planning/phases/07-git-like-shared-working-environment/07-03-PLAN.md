<interfaces>
- Shared authority is branch/base OID/revision; shell markers are applied-state metadata only.
- Newly materialized `AutoApplyDefault` is true; explicit false persists; optional shell override is separate.
- `State` embeds a bounded `Shells` map. Each shell record separates applied revision/baseline, capture baseline, durable unpublished local delta, present-at-attach exclusions, pending transition/revision/resolution token, behind/conflict/error metadata, and recent idempotent operation receipts.
- `model.ShellCredential` is a private request value containing the opaque shell ID and decoded 32-byte capability. `ShellCapabilityVerifier` is `SHA-256("zsh-pro/worktree-shell-capability/v1" || capability)` and comparisons use `crypto/subtle`; the raw capability has no JSON/text marshaler and is never stored, logged, formatted, or returned by Service.
- Every private Service method receives the credential. Inside `WithTransaction`, credential verification occurs after strict state decode and before operation-receipt lookup, conflict inspection, or mutation; public shared `Status`/`Diff` and optional ID-only shell-status projection remain value-free and do not become mutation authority.
- `worktree.json` is the only canonical causal document. `worktree.lock` is coordination and `events.jsonl` is a bounded value-free projection; there is no independently renamed canonical `shells/<id>.json` document.
- Runtime callers supply their context; StateStore preserves cancellation/deadline and never extends it.
- `OpenStateStore(path)` authenticates and owns its opened root descriptor. `NewStateStoreFromAuthenticatedRoot(*os.File)` duplicates and immediately re-authenticates the already-authenticated root descriptor without pathname access; the caller retains the input descriptor, the returned StateStore owns only its duplicate, constructor failure closes only partial duplicates, and idempotent `Close` closes owned descriptors exactly once.
</interfaces>

## Trust Boundaries

| Boundary | Description |
|---|---|
| configurable root -> descriptors | Local path becomes shared mutable authority |
| shell snapshot -> per-shell state | Initial/ongoing state may contain ambient or secret data |
| compaction/conflict -> stale shell | Missing causal history could authorize unsafe publication |
| shell ID/capability -> private Service transition | Caller-supplied authority must be verified against the durable shell record inside the canonical lock |
| authenticated RuntimeRoot descriptor -> StateStore | An authenticated runtime root crosses into close-owned descriptor-relative canonical storage without a path reopen |
