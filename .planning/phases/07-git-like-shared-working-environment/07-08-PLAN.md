<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| current shell -> framed decoder | Executable process state crosses into typed Go values |
| live patch -> generated zsh bytes | Durable changes become source evaluated in the parent shell |
| authenticated RuntimeRoot -> runtime factory -> operation-scoped Service | Value-bearing operations bind late to canonical descriptor authority |
| Service prepare result -> private parent-shell program | Revision/token/fingerprint must cross the process boundary without exposing patch bytes through public metadata or creating CLI-owned zsh syntax |

| T-07-32 | Information Disclosure | frames/source/errors | high | mitigate | Admission before persistence, pinned-secret absence, private in-memory transport, raw diagnostic suppression, and canary tests. |
