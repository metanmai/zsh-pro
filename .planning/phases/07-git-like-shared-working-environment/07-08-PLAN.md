<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| current shell -> framed decoder | Executable process state crosses into typed Go values |
| live patch -> generated zsh bytes | Durable changes become source evaluated in the parent shell |
| runtime factory -> authenticated Service | Value-bearing operations cross descriptor/authority boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-31 | Elevation of Privilege | Decode/EmitLivePatch | high | mitigate | Bounded typed frames, complete validation, hostile-name rejection, safe quoting, sole emitter, and zsh -n/apply tests. |
| T-07-32 | Information Disclosure | frames/source/errors | high | mitigate | Admission before persistence, pinned-secret absence, private in-memory transport, raw diagnostic suppression, and canary tests. |
| T-07-33 | Tampering | descriptor/service replacement | high | mitigate | Exact injected Service/descriptors, no caller paths, pre/post authentication, and replacement tests. |
| T-07-34 | Denial of Service | frame/render size | medium | mitigate | 2 MiB/10,000 caps, bounded transforms, no child-zsh capture, and boundary tests. |

ASVS Level 1 applies; all high-severity decode/codegen/authority gates are blocking.
</threat_model>
