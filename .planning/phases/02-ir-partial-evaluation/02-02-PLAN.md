## Design forks resolved in this plan

- **Templater placement → reading (a): templater lives in `core/shell/zsh` behind a new `shell.Regenerator` interface.** The milestone invariant pins zsh-syntax codegen to the zsh package ("only `core/shell/zsh` writes zsh syntax" — ROADMAP §invariants). Phase 2's *forward* declarative templater honors that strictly and pre-positions Phase 4's `emit.go` (the *reversal* codegen). `core/ir` calls `Regenerate(entry)` via the interface and never emits zsh syntax itself. Reading (b) — forward templating inside `core/ir` — is rejected for invariant cleanliness (RESEARCH Pitfall 5 / Open Question 1).
- **Oracle snapshot access → compare `model.IdentitySet` via the already-exported `Provider.Introspect(path)`.** `introspectScript` is an unexported const, but `Introspect` already runs it under `zsh -f` + 5s timeout and returns structured `model.IdentitySet` (Aliases/Functions/Env/Path/Options). D-08's "byte-identical state tables" maps cleanly onto `IdentitySet` map/slice equality. This reuses one source of truth for the snapshot format and needs NO new exported helper and NO inlined throwaway script (RESEARCH Open Question 2, recommended option).
