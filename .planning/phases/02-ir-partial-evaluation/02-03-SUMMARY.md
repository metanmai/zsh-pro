# Phase 2 Plan 3: Array-Assignment Round-Trip Gap Closure Summary

Closes the UAT round-trip defect where a single-name ARRAY assignment (`plugins=(git zsh-autosuggestions zsh-syntax-highlighting)`, single-line and multi-line) silently regenerated as a bare `plugins=` — dropping the array value and breaking oh-my-zsh plugin load. Array assignments are now detected at parse time (`model.Block.Array`), routed imperative (verbatim Text), and pinned by an oracle fixture asserting the full `(...)` literal survives.

## What Was Built

1. **Parse-time array detection (Task 1)** — Added an additive `Array bool` to `model.Block` (core/model stays stdlib-only) and set `b.Array = true` when `a.Array != nil` in all three `Assigns` capture loops in `parse.go`: the plain `=` CallExpr loop, the `export`/`typeset`/`declare`/`local`/`readonly` CallExpr loop, and the `*syntax.DeclClause` loop. The scalar `a.Value` capture is untouched (mvdan/sh leaves `a.Value == nil` for arrays, so `b.Value` correctly stays empty). The full `(...)` span — multi-line included — survives in `b.Text`.

2. **Imperative routing (Task 2)** — `routeManaged`'s `KindAssignment` arm now rejects `b.Array` alongside the existing multi-name (BL-02) and `+=` (WR-01) guards, so an array assignment is never managed in any admitted category (CatEnvironment / CatPath / CatSecrets). The agnostic boundary holds: `core/ir/route.go` (non-test) imports only `core/model`.

3. **Oracle coverage + defensive guard (Task 3)** — Extended the round-trip oracle fixture with a single-line `plugins=(...)` and a multi-line `marr=(...)` array; the oracle now asserts (via `bytes.Contains`) that the full `plugins=(git zsh-autosuggestions zsh-syntax-highlighting)` literal and the multi-line `marr=(` + its elements survive in the regenerated bytes, while the existing `model.IdentitySet` `reflect.DeepEqual` equality across all 5 declarative classes still holds. Added a belt-and-suspenders empty-Value guard in `regen.go` (`if e.Value == "" { return e.Text }`) so a forced-managed array via `OverrideManaged` falls through to verbatim Text instead of emitting a bare `name=`.

Note on TDD mechanics: the pre-commit hook runs `golangci-lint` (which includes a typecheck pass) on staged Go. A RED test that fails to *compile* (referencing a not-yet-existing field) would be blocked by the hook. The additive `model.Block.Array` field was therefore introduced in the Task-1 RED commit so the test compiles and lints clean while still failing at runtime (parse.go does not set it yet) — preserving an honest RED that passes the typecheck gate. This is the same belt-and-suspenders pattern used for the regen guard RED (which compiles, lints clean, and fails at runtime).

## The Bug, Closed

Before: `plugins=(git zsh-autosuggestions zsh-syntax-highlighting)` → `plugins=` (array dropped; oh-my-zsh loads zero plugins; git aliases/functions, autosuggestions, syntax-highlighting all vanish). After: the array routes imperative and round-trips byte/behavior-faithfully as its full verbatim `(...)` span. Pinned by `bytes.Contains(regen, "plugins=(git zsh-autosuggestions zsh-syntax-highlighting)")` so a future regression resurfaces in CI, not as another silent UAT drop.
