TWO MANDATORY DIVERGENCES from the snapshot analog (both verified under zsh 5.9 — see RESEARCH Patterns 1-2, Verification Log V1-V4, and PATTERNS "DIVERGENCE 1/2"):
(i) The apply/deactivate loaders are PLAIN functions — NO `emulate -L zsh`, NO `setopt LOCAL_OPTIONS`. The existing `introspectScript` opens with `emulate -L zsh`; copying that header into the apply path silently auto-reverts options at function return -> a FALSE no-go on the options class. `emulate -L zsh` is correct ONLY in the read-only `snapshot()` function.
(ii) NO `typeset -U path`. Rebuild PATH from the captured `ZP_BASE_PATH` via plain array assignment. `typeset -U` mutates a base that contains a pre-existing duplicate and fails the byte-identical bar (V3c). This corrects the prior `.planning/research/` files, which recommended `typeset -U` as a no-growth backstop.

D-07 (sandboxing): the entire spike runs in a sandboxed `zsh -f -c <script>` subprocess (no rc files) and must NEVER mutate the user's real, live shell. `-f` suppresses rc-file sourcing but NOT environment inheritance (Pitfall 5): the synthetic-fixture pass MUST set a controlled clean base (`export PATH=/usr/bin:/bin`) before `ZP_BASE_PATH="$PATH"`.

- THREE extensions required for the spike (PATTERNS "Three extensions"): (1) sort keys `(@k)` -> `(@ok)` for a stable diff; (2) dump alias/function BODIES via `print -r -- "$k=${aliases[$k]}"` (needed for shadow-restore verification); (3) add the 6th class `##FPATH##` (`for p in $fpath`), emit env as name+VALUE (`"$k=${(P)k}"`) and PATH as the order-exact scalar `"$PATH"`, and options name-only-when-on as today.

Proposed Manifest JSON shape to instantiate in the two fixtures — from RESEARCH "Proposed Manifest JSON Shape" (lines 372-412). Field names are a recommendation (Assumption A1); the SHAPE is load-bearing:
- top-level: `"profile"` (string, == branch name, informational), `"schema"` (string, e.g. "v1")
- `"env"`: array of `{ "name", "applied", "original"? }` — PRESENCE/ABSENCE of `"original"` encodes unset-vs-empty (Pattern 4): no `original` key -> was unset -> deactivate unsets; `"original": ""` -> was empty; `"original": "old"` -> restore "old". Drift-guarded reverse (Pattern 3).
- `"lists"`: array of `{ "name", "additions": [], "deletions": [] }` for PATH/FPATH — add/delete deltas vs the captured base (Pattern 1); NEVER an absolute PATH. `compinit` is NOT represented here.
- `"aliases"`: `{ "added": { name: body }, "shadowed": { name: priorBody } }` — prior bodies for shadow-restore (Pattern 5); deactivate unaliases `added`, restores `shadowed`.
- `"functions"`: `{ "added": [name], "shadowed": { name: priorBodyText } }` — deactivate `unset -f` each `added`, restores `shadowed` via `functions[name]=...`.
- `"options"`: array of `{ "name", "enabled", "was_on" }` — restore exact prior on/off, not a blind toggle.

Sandboxed subprocess shape (informational; the Go pin is in Plan 01-02) — core/shell/zsh/introspect.go:42-53:
