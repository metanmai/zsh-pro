<objective>
Surface the severity built in 02-01 across both output surfaces: add a non-omitempty `severity` string to the JSON wire `Issue`, map it in `toDTO` via `Severity.String()`, switch the envelope `issues_found` flag to the `HasActionableIssues()` predicate (so it can never disagree with `exit_code`), and make the human report use a softer glyph for advisories with a separate advisory tally in the summary.

Purpose: Completes SEV-01 (self-describing severity on every issue, both surfaces) and SEV-02 (issues_found is actionable-only and consistent with exit_code). In Phase 2 every issue is actionable, so the JSON output is behavior-stable except for the additive `severity` field; the advisory branch is exercised by hand-constructed test fixtures and goes live in Phase 3.

Output: `core/dto/analysis.go` (wire field), `core/render/json.go` (mapping + predicate), `core/render/human.go` (glyph + tally), and `core/render/render_test.go` (severity-presence, advisory-only-envelope, human marker+tally tests).
</objective>
