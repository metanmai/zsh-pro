<objective>
Add the severity mechanism to the domain layer: a two-value `Severity` type whose zero value is `SevActionable`, a `Severity` field on `model.Issue`, a single `Analysis.HasActionableIssues()` predicate, and an `ExitCode()` that consults the predicate instead of counting raw issues. This is the contract layer the wire/render plan (02-02) compiles against.

Purpose: Delivers the SEV-01 type foundation and the load-bearing SEV-02 exit-code semantics. Because `SevActionable` is the zero value (D-01), every existing `Issue{}` literal in the reconciler and testgen stays correct with zero edits, and the four existing issue kinds remain `actionable` / exit-3.

Output: `core/model/issue.go` (Severity type + String() + field), `core/model/analysis.go` (HasActionableIssues + updated ExitCode), and the `core/model` truth-table tests pinning SEV-01/SEV-02.
</objective>
