func (p Provider) Introspect(path string) (model.IdentitySet, error) {
    ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
    defer cancel()
    cmd := exec.CommandContext(ctx, "zsh", "-f", "-c", introspectScript, buildinfo.Name, path)
    var out bytes.Buffer
    cmd.Stdout = &out
    if err := cmd.Run(); err != nil {
        return model.IdentitySet{Available: false}, err
    }
    return p.parseIntrospect(out.String()), nil
}

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → core/store | A `model.Profile` (and later, profile/branch names) crosses from the application into the store; values originate from a parsed `~/.zshrc`, treated as untrusted data. |
| core/store → git binary | The store hands argv to a subprocess; a malicious profile/branch name could be read as a flag or traverse a ref path. |
| profile.json bytes → git object DB | Serialized bytes become a committed blob; a leaked secret here is permanent in history. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | git stderr forwarded to the user | mitigate | `mapGitError` maps exit/err to `errStore` sentinels; raw stderr never embedded (acceptance criterion asserts no "fatal:" substring). ASVS V7. |
| T-03-02 | Tampering | Dynamic value resolved during serialization (machine-locking / accidental injection) | mitigate | DTO passes `Value` through verbatim; acceptance criterion asserts `$HOME/go` literal survives, no `util.ExpandHome` in `core/store/dto.go`. ASVS V5/V6. |
| T-03-03 | Information Disclosure | Secret literal committed to the tree via the JSON payload | mitigate (partial — full capture is Plan 03) | Serialization carries `Secret *SecretRef` with a cleared `Value`; the round-trip test proves a SecretRef entry serializes with no literal value. The capture+exclusion orchestration is Plan 03. |
| T-03-SC | Tampering | npm/pip/cargo installs | accept (N/A) | No package-manager installs in this phase; PROF-01 forbids new Go modules. RESEARCH Package Legitimacy Audit table is empty by design (no registry installs). |
</threat_model>
