<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → Store (branch/profile names) | Names flow into `git` argv and `refs/heads/<name>` paths; originate from user/CLI input, untrusted. |
| Store → git object DB (Commit) | A Commit moves a ref; on a non-bare repo this could corrupt a shared working tree (the conda-race class PROF-02 forbids). |
| profile.json blob → committed tree | A leaked secret in the JSON is permanent in history (full mitigation in Plan 03; this plan keeps the payload faithful). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02 | Tampering | Branch/profile name argument injection or ref-path traversal | mitigate | `validBranchName` rejects leading `-` and non-`[A-Za-z0-9._/-]`; refs built only as `refs/heads/<validated>`; names passed as distinct argv via gitRunner (never a shell string). ASVS V5. Acceptance criterion asserts `-rf`/`../etc`/empty are rejected. |
| T-03-04 | Tampering / Information Disclosure | Shared-HEAD working-tree contention across terminals (conda race) | mitigate | Bare repo (`git init --bare`) — no working tree, no checked-out HEAD; Commit moves refs in the object DB only; Read via `git show`; zero `git status`/`checkout`/`reset` in store.go (acceptance criterion). PROF-02/D-12. |
| T-03-01 | Information Disclosure | Raw git error (e.g. `fatal: path ... does not exist`) on a missing profile | mitigate | `Read` uses `catFileExists` as a clean existence probe and returns `ErrProfileNotFound` (zsh-pro-phrased) instead of letting `git show` print raw. D-11/Pitfall 4. |
| T-03-05 | Tampering | Non-deterministic commits flaking history-sensitive tests | accept (low) | `runCommit` sets `GIT_AUTHOR_*`/`GIT_COMMITTER_*` incl. a fixed `*_DATE`; tests assert on CONTENT (`Read` → DeepEqual), not on commit SHAs. Pitfall 2. |
| T-03-SC | Tampering | npm/pip/cargo installs | accept (N/A) | No package-manager installs; PROF-01 forbids new Go modules. |
</threat_model>
