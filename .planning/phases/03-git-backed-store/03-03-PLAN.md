## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Entry.Value (literal secret) → keychain/vault backend | The literal secret value crosses from the in-memory profile into an OS keychain or a local file; it must never appear on argv, in logs, or in the committed git tree. |
| Store → keychain CLI (security/secret-tool) | The store hands a key (and pipes a value) to a subprocess; the value off-argv is the controlled boundary. |
| post-exclusion profile.json → committed tree | The serialized profile becomes a permanent blob; a SecretRef (not the literal) is what may cross. |

Vault file `.gitignore`'d + plumbing stages only profile.json/profile.zsh. ASVS V12, Pattern 1/4. |
