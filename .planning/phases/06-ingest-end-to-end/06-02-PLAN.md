<interfaces>
Contracts from 06-01 and Phase 3:
- `BeginIngest` supplies one opaque transaction containing exact expected ref/Profile presence and a candidate object quarantine.
- `prepareSecrets` is side-effect free and returns a redacted Profile, value-free report, and pending backend mutations before any durable effect.
- `gitRunner.updateRefCAS` is the existing one-shot primitive; this plan adds a long-lived `git update-ref --stdin` transaction so prepare locks the expected ref before backend writes.
- `Store.Commit(ctx,branch,profile,msg) (WithheldReport,error)` remains source-compatible for existing callers; only ingest uses the full typed outcome.
- Per-instance seams, never package globals, drive failure timing and authoritative ref reads.
</interfaces>
