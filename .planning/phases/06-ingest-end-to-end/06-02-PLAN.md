<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| arbitrary zsh source -> Parser/IR | User configuration may contain executable shell syntax, substitutions, malformed input, and secrets. |
| model profile -> secret backend and Git ref | Literal secret data crosses into the keychain/vault while only redacted data may reach committed blobs. |
| CLI-selected path -> install/master mutation | A user-selected file is read, installed, and atomically rewritten. |
| store commit -> final file promotion | Two separately durable resources can fail at different points. |
| domain result -> human/JSON output | Withheld metadata is public while secret values and zsh text are private. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- | --- |
| T-06-02-01 | Elevation of Privilege | `runIngest` source handling | critical | mitigate | Use only Provider.Parse + ir.Build; never call Introspect/source/eval; inject a panic-on-Introspect provider and retain dynamic expressions verbatim in tests. |
| T-06-02-02 | Information Disclosure | `Store.Commit` and ingest renderers | critical | mitigate | Reuse Commit's fail-closed exclusion, map only Name/StartLine into DTOs, assert literal absence from committed blobs and both output modes. |
| T-06-02-03 | Tampering | managed/imperative partition | high | mitigate | Use only `EffectiveManaged`, account every parsed block exactly once, commit only the managed slice, and compare every unmanaged Text byte in master output. |
| T-06-02-04 | Tampering | selected path and stale promotion | high | mitigate | Resolve an absolute target through the landed installer boundary and use Plan 06-01's expected-byte guarded promotion. |
| T-06-02-05 | Tampering | concurrent `main` commits | high | mitigate | Rely on landed Commit ref CAS and secret compensation; test conflict prevents file promotion and never report success. |
| T-06-02-06 | Repudiation | commit-success/file-failure outcome | high | mitigate | Return a distinct error naming the advanced `main` baseline and unchanged file, then prove idempotent rerun convergence. |
| T-06-02-07 | Denial of Service | malformed markers/store/backend failure | medium | mitigate | Reuse installer/store fail-closed paths; prepare all file bytes before Commit and preserve source on any pre-promotion error. |
