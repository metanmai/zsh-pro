</objective>

<interfaces>
Contracts from 06-01 and Phase 3:
- Public `BeginIngest(ctx, installInitializationID)` supplies one main-bound opaque transaction with invariant ExpectedRevision/RefPresent and separate ProfileObjectPresent evidence, private index/object quarantine, and pre-I/O-reserved authenticated state.
- `prepareSecrets` is side-effect free and returns a redacted Profile, value-free report, and pending backend mutations before any durable effect.
- `gitRunner.updateRefCAS` is the existing one-shot primitive; this plan replaces ingest/legacy commit ref mutation with a long-lived fixed `git update-ref --no-deref --stdin` transaction. Start acknowledgement is live-only; prepare acknowledgement alone locks the opaque validated head ref before backend writes.
- `Store.Commit(ctx,branch,profile,msg) (WithheldReport,error)` remains source-compatible through an explicit outcome adapter matrix and an unexported generic branch-aware transaction constructor; it must not call the public main-only Begin wrapper. Only ingest uses the full typed publication/cleanup outcome.
- `validatedHeadRef` is unexported and cannot be built from arbitrary ref text. Public ingest receives the fixed-main constructor only; the private legacy path first validates the branch name, then constructs `refs/heads/<branch>` internally. Both paths use one typed mutation encoder and fixed no-deref ref operations.
- Per-instance seams, never package globals, drive failure timing and authoritative ref reads.
</interfaces>
