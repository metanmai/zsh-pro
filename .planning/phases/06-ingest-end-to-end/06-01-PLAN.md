</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Mutable main ref -> exact baseline token | Concurrent commits can otherwise mix probe, Profile bytes, tree seed, and parent. |
| Candidate object environment -> final store | A failed candidate must not mutate a fresh initializer's sealed tree before ref preparation. |
| Opaque token -> Store transaction registry | Cross-instance/reused tokens could abort another transaction. |
| Abort cleanup -> initializer rollback | Cleanup/durability evidence decides whether fresh-root deletion is safe. |
