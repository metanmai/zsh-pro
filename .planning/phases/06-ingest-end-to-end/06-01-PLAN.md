## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Mutable main ref -> exact baseline token | Concurrent commits can otherwise mix probe, Profile bytes, tree seed, and parent. |
| Candidate index/object environment -> final store | Inherited Git variables or shared indexes must not redirect or leak candidate state into the final store. |
| Opaque initialization/token pair -> Store transaction registry | Cross-instance, wrong-initialization, or reused authority could begin, abort, or roll back another Store's state. |
| Abort cleanup -> initializer rollback | Cleanup/durability evidence decides whether fresh-root deletion is safe. |
| Quarantine pathname -> retained quarantine object | A concurrent rename/replacement must not redirect recursive cleanup into unowned state. |
