Create the exact-revision baseline token and isolated candidate-object transaction that every later ingest effect depends on.

Purpose: Make public ingest main-only, reserve authority before all I/O, model absent main without fake object reads, bind every Git command to a hermetic bare store, and make recursive cleanup evidence replayable and identity-safe at every child.
Output: Reviewed immutable execution base, neutral optional-revision outcomes, main-only Begin/Abort surface, pre-I/O reservation, hermetic private Git plumbing, recursive identity-bound cleanup, aggregate initializer eligibility, and focused tests.
</objective>

Current contracts to preserve and extend:
- `(*Store).InitForInstall(ctx) (InstallInitialization, error)` currently seals a newly created store tree. This plan adds an opaque ID generated by the exact Store and removes caller-supplied creation booleans from Begin/rollback authorization.
- `(*Store).Read(ctx, branch)` currently addresses a mutable branch and cannot combine exact durable presence with the same-revision Profile read. Public ingest does not inherit that generic branch parameter; legacy generic branch support remains private to 06-02's compatibility adapter.
    - `gitRunner` owns Git subprocess environment/argv construction, object writers, refs, and per-instance test seams. Current inherited Git config/work-tree variables are untrusted.
    - The fixed Init baseline is main pointing at an empty tree without `profile.json`; a later committed empty Profile contains a durable empty profile object and must select re-ingest semantics.
    - Landed `installInitializationState.rollback` snapshots by pathname and calls `os.RemoveAll`; Phase 6 must not reuse that pathname-recursive pattern for transaction quarantine cleanup.
</interfaces>
