```
begin = "# >>> zsh-pro >>>"; end = "# <<< zsh-pro <<<"
render() -> deterministic canonical block (begin..end inclusive)
scan for begin/end:
  no begin, no end:      create (empty file) OR append-at-EOF (single leading \n)
  begin present, end present, end AFTER begin: replace first inclusive region; drop dup regions; preserve outside bytes
  UNBALANCED (begin w/o end | end w/o begin | end-before-begin | interleaved): REFUSE-AND-FAIL, write NOTHING (C4 — no slice-on-(-1), no region-to-EOF delete)
```

```
# >>> zsh-pro >>>
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `zsh-pro install` -> `~/.zshrc` (symlink-resolved) | The installer rewrites the user's login file; clobbering content outside the markers, corrupting a symlink, or mishandling unbalanced markers is destructive data loss. |
| cached loader file -> every shell start | The stub sources a cached loader file on every interactive start; a group/world-writable cached file/dir lets a DIFFERENT principal execute code in the victim's shell (attacker->victim, not self->self). |
| emitted code -> verb `eval` | The verb `eval`s emitted apply/deactivate code into the live shell; unvalidated code is arbitrary execution, and secret-bearing code can leak into history/argv. |
| broken/absent binary/loader -> `.zshrc` startup | A failure that propagates a non-zero exit or hangs could lock the user out of a working shell. |
