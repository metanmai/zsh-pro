| Boundary | Description |
|----------|-------------|
| persisted profile -> runtime resolver | Redacted SecretRef metadata is transformed into a live shell value only for the active switch. |
| composition root -> interface constructors | Concrete pointers cross package boundaries as interfaces and may carry a typed nil. |
