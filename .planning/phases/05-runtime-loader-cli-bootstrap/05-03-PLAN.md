Retain source byte offsets for each complete region so only inclusive real marker regions are replaced, duplicate regions collapse deterministically, and all unrelated bytes are copied verbatim. Add table-driven regression fixtures covering quoted marker strings, prefix text, suffix comments, CRLF, no final newline, duplicate regions with intervening content, and each malformed exact-marker ordering. <threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| installer -> .zshrc | User-owned shell configuration is rewritten and must not lose unmanaged bytes. |
| candidate loader -> cached loader | A replacement loader is sourced by future shells and must be valid, private, and atomically promoted. |
| environment path inputs -> filesystem | HOME, ZDOTDIR, and ZSHPRO_HOME select write targets and are untrusted process inputs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-03-01 | Tampering | marker scanner | high | mitigate | Exact physical-line markers, malformed-pair refusal, and byte-preservation regression fixtures. |
| T-05-03-02 | Elevation | cached loader permissions | high | mitigate | Enforce directory 0700 and loader 0600 after replacement; preserve .zshrc policy separately. |
| T-05-03-03 | Tampering | candidate cache promotion | high | mitigate | Validate the staged candidate with a context deadline before atomic rename; retain known-good cache on failure. |
| T-05-03-04 | Tampering | HOME/ZDOTDIR/ZSHPRO_HOME path selection | high | mitigate | Require checked non-empty absolute bases before filesystem mutation. |
| T-05-03-05 | Denial of Service | install-time zsh validation | medium | mitigate | CommandContext deadline plus exact temporary-file cleanup. |
| T-05-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package-manager installation occurs; implementation uses Go standard library and existing optional tools. |
</threat_model>
